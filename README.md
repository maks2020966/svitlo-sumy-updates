# Світло Суми — оновлення

Публічний репозиторій оновлень Android-застосунку. APK зберігаються у GitHub Releases.

Для нової версії: спочатку опублікуйте перевірений APK у Releases; потім оновіть update.json: versionCode, versionName, apkUrl і sha256. Застосунок перевіряє цілісність і цифровий підпис APK перед встановленням.

Не публікуйте тут приватний ключ підпису, паролі чи токени.
